# تجربة: المدرب بشكل هيرو (مؤجّلة لتحديث لاحق)

مو مربوطة بالتطبيق. نرجعلها بعد ما نخلص الأساسيات.

- `anat-hero-outfit.patch`: فانيلة سودة بدون ردون + H ذهبي على الصدر، بنطلون طويل أزرق غامق، لحية أغمق.
  تطبيقها للتجربة بس: `patch anat.js < experiments/hero-coach/anat-hero-outfit.patch`
- فكرة مكمّلة: وجه هيرو الأنمي بزاوية شاشة التمرين ويا فقاعة كلام (نصيحة الأداء، الراحة، آخر جولة، رقم قياسي).

الباقي قبل ما تنزل: تنعيم حافة الفانيلة عند الكتف، خط أزرق على الحواف وجنب البنطلون، بنطلون أوسع (جوگر)،
ومقارنة على موبايل حقيقي لأن الرسم بالسيرفر جودته أقل. الحل الكامل (هيرو 3D أنمي) يحتاج أداة توليد 3D مدفوعة.
