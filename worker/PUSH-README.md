# سيرفر «التذكيرات» · hero-push

Cloudflare Worker + قاعدة D1 + Cron كل 5 دقايق. يرسل إشعارات (Web Push) بالأوقات اللي يختارها المستخدم من «ملفي ← التذكيرات».

**الخصوصية:** يحفظ بس: عنوان إشعارات الجهاز (يصدره المتصفح)، المنطقة الزمنية، اللغة، أوقات التذكير. ما يستلم أكل ولا وزن ولا اسم.
الإشعار يوصل **بدون محتوى**، والنص يختاره الـservice worker بالجهاز (حسب وقت اليوم واللغة). كل هذا مكتوب بـ`privacy.html` و`terms.html`.

## الإعداد (مرة وحدة، من جذر المستودع، يحتاج Node و`wrangler` مسجّل دخول بحساب Cloudflare)

1. **مفتاح VAPID** (المفتاح الخاص يبقى عندك، ما يدخل المستودع؛ `.gitignore` يمنع `*.jwk.json`):
   ```
   node worker/gen-vapid.mjs > vapid.jwk.json
   ```
2. **قاعدة D1:**
   ```
   npx wrangler d1 create hero-push
   ```
   انسخ `database_id` اللي يطلع وحطه بـ`worker/wrangler.push.toml` مكان `PUT_D1_DATABASE_ID_HERE`، وبعدها:
   ```
   npx wrangler d1 execute hero-push --remote --file=worker/schema.sql -c worker/wrangler.push.toml
   ```
3. **المفتاح كـSecret** (وبعدها امسح الملف):
   ```
   npx wrangler secret put VAPID_JWK -c worker/wrangler.push.toml < vapid.jwk.json
   del vapid.jwk.json
   ```
4. **النشر:**
   ```
   npx wrangler deploy -c worker/wrangler.push.toml
   ```
5. **فحص:** افتح `https://hero-push.baghdadhurr.workers.dev/health` ← `{"ok":true}`، و`/key` ← `{"key":"B..."}` (المفتاح العام).
   إذا الرابط اللي طلع غير هذا (اسم الحساب مختلف)، غيّر `PUSH_URL` بأول قسم v110 بـ`app-main.js` وبعدها `python3 tools/release.py <رقم>`.

## قبل ما تنشر نسخة التطبيق اللي بيها التذكيرات

لازم تجرّب على **موبايل حقيقي** (المتصفح الداخلي ما يدعم الإشعارات):
- أندرويد/Chrome: افتح التطبيق، ملفي ← التذكيرات ← «فعّل التذكيرات» ← اسمح ← «جرّب إشعار». لازم يوصل خلال ثواني. جرّب بعدها وقت بعد دقيقتين وسكّر التطبيق.
- آيفون (iOS 16.4 فما فوق): لازم تضيف التطبيق للشاشة الرئيسية أول (مشاركة ← إضافة إلى الشاشة الرئيسية)، وتفتحه من الأيقونة.

## الحدود والكلفة

- الخطة المجانية: 50 طلب خارجي لكل تشغيل، فالـCron يرسل **40 إشعار كحد أقصى كل 5 دقايق**. إذا زاد المشتركين بنفس الوقت اللي يتأخرون ينلحقون بالتشغيل الجاي (حد 10 دقايق).
  لعدد أكبر انتقل لخطة Workers Paid (5$ بالشهر، 1000 طلب لكل تشغيل).
- الحد الأقصى **20,000 مشترك** (`MAX_ROWS`)، والـCron يقرأ القاعدة صفحات من 500 صف. D1 المجاني يكفي لهذا العدد.
- الاشتراك اللي ما تجدّد (التطبيق يجدّده كل يوم يفتحه) ينمسح تلقائياً بعد **60 يوم** (`STALE_DAYS`)، وهذا اللي يغطي حالة حذف التطبيق بدون إطفاء التذكيرات.
- لو فشل إرسال إشعار (خطأ مؤقت من خدمة الإشعارات) يتعاد بالتشغيل الجاي ضمن 10 دقايق. الحجز ذري، فتشغيلين متداخلين ما يرسلون نفس الإشعار مرتين.
- إذا خدمة الإشعارات رجّعت 404 أو 410 (الجهاز ما عاد موجود) يمسح السيرفر الاشتراك تلقائياً.

## الأمان

- يرسل فقط لعناوين خدمات إشعارات معروفة (Google/Apple/Mozilla/Microsoft) على https، وما يقبل أي رابط ثاني.
- CORS مقفول على `ALLOWED_ORIGINS` (نفس قائمة `hero-snap`). إذا صار للتطبيق دومين جديد ضيفه هناك.
- التسجيل (`/subscribe`) محدود بـ100 طلب بالساعة لكل IP (واسع لأن الشبكات الموبايلية تشارك IP). **ينصح** بإضافة قاعدة Rate Limiting من لوحة Cloudflare (Security ← WAF ← Rate limiting rules) على المسار `/subscribe` كحماية إضافية.
- `/test` محدود بمرة كل 30 ثانية لكل جهاز. حجم الطلب محدود 4KB، والأوقات تنفحص (حد أقصى 5 تذكيرات).

## الحذف

المستخدم يطفي التذكيرات من «ملفي» أو يمسح كل البيانات ← التطبيق يطلب `/unsubscribe` وينمسح الصف. لمسح الكل يدوياً: `npx wrangler d1 execute hero-push --remote --command "DELETE FROM subs" -c worker/wrangler.push.toml`.
