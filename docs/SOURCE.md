## شنو المصدر؟

من نسخة 81، **هذا المستودع نفسه هو المصدر**. ماكو خطوة بناء: الملفات اللي هنا هي نفسها اللي ينشرها GitHub Pages.

- نسخ 1 لحد 80 انبنت بصفحة Claude (ملف tracker.html)، وكان سكربت `pwa_build.py` يحولها لموقع. الملفات اللي جان يحتاجها انمسحت ويا جلسات العمل القديمة، فالسكربت محفوظ بس كمرجع: `tools/legacy/pwa_build_v75.py`.
- أي تعديل جديد ينسوى مباشرة على `index.html` (أو بسكربت تعديل يتحفظ بالمستودع، مثل `i18n/apply83.py` و`src84/apply84.py`).

## شلون تنشر نسخة جديدة

```bash
# 1) سوّي التعديل على index.html
# 2) جهّز النسخة (يغير الرقم ويحدّث الـservice worker)
python3 tools/release.py 85
# 3) جرّبها محلياً
python3 -m http.server 8000      # وافتح http://localhost:8000
# 4) انشرها
git add -A && git commit -m "هيرو · نسخة 85: ..." && git push
```

لازم تغيّر رقم النسخة بكل نشر، لأن اسم ذاكرة الـservice worker هو اللي يخلي موبايلات الناس تنزّل التحديث. للفحص بدون تغيير: `python3 tools/release.py --check`.

## إذا انمسح المستودع أو الحساب

1. سوّي حساب GitHub (أو استعمل الموجود) ومستودع جديد **Public** اسمه `Hero`.
2. من نسخة الطوارئ (الفلاش): `git clone hero.bundle Hero` يرجّع كل الملفات ويا كل التاريخ.
3. `git remote set-url origin https://github.com/<الحساب>/Hero.git` وبعدها `git push -u origin main`.
4. بالمستودع: Settings ← Pages ← Source: Deploy from a branch ← `main` و`/ (root)` ← Save.
5. الرابط يصير `https://<الحساب>.github.io/Hero/`. إذا تغيّر الحساب يتغيّر الرابط، فحدّث رابط البايو بـ@heroapp.iq.

**بيانات المستخدمين** محفوظة بموبايل كل واحد (بالمتصفح)، مو بالمستودع. إذا تغيّر الرابط، كل واحد ينقل بياناته من ملفي ← النسخة الاحتياطية (تنزيل بالرابط القديم، استيراد بالجديد).
